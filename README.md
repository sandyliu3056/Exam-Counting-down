# 英語學習站

給高三統測考生的英文家教系統：考前倒數、閱讀測驗、單字卡、單字小考、學習紀錄，老師可登入查看學生練習狀況與錯題。純前端（HTML / CSS / JS），不需要伺服器，放上 GitHub Pages 即可使用，iPhone 可「加入主畫面」當 App 用。

頁面分成七組：首頁 · 閱讀（閱讀測驗、每日新聞）· 單字（單字卡、單字庫、片語）· 題目（選擇題、克漏字）· 翻譯（翻譯練習）· 📈 紀錄（學習紀錄；老師還有學生狀況，老師按「紀錄」會先打開學生狀況）· 設定。電腦上是上方的資料夾分頁加上小分頁按鈕；手機上是畫面下方的七個按鈕，最後一個「☰ 更多」裡有設定、使用導覽、帳號與外觀。每一頁都有自己的網址（例如 `#/translate`），iPhone 往回滑可以回到上一頁。練習時（選擇題、翻譯、單字卡、閱讀）手機會進入專心模式，按「✕ 結束」會先確認。

單字卡、單字小考和單字庫的「單元」下拉選單都一樣：全部（單字＋片語）；依程度 A1 起步、A2 入門、B1 基礎、B2 進階、C1 挑戰、C2 頂尖（A1–B2 附 7000 單字的 Level，每個都附字數）；其他：片語、統測高頻 3000 字（選了會多一個下拉選單，可以選全部或第 1–30 組，每組 100 字，最常考的在前面）；✏️ 老師自訂（全部，以及老師取名的每個單元）。從片語頁選了一個類別再按「🃏 單字卡」或「📝 小測驗」過來時，單元選單會多一組「片語（依類型）」顯示那一類。

預設介面為 **中文**，可切換 English（電腦在右上角的選單，手機在最上面標題列的語言下拉選單（中文／EN），「更多」裡也有）；也可切換手寫風 / 標準字體與六種配色主題。標題列會一直顯示今天日期、現在時間與考試剩餘天數，點一下會打開可愛的日曆，選一天就能更改考試日期；首頁有積木凸點風格的世界地圖（藍色海洋、綠色陸地、土色沙漠）。

## 帳號與權限

- 右上角「登入 / 註冊」。身分分為 **學生** 與 **老師**。
- 註冊老師帳號需要 **老師邀請碼**。本機模式預設為 `teacher2028`，老師登入後可在「設定」更改；雲端模式的第一個老師用 SQL 升級（見下方），邀請碼由老師自己設定。
- 只有老師登入後才看得到「學生狀況」分頁與編輯功能（新增文章、單字），也只有老師能改考試名稱；考試日期學生可以自己改。
- 學生不登入也能練習，但建議登入，紀錄才會對應到名字。

## 兩種使用模式

### 1. 本機模式（預設，不用任何設定）

帳號、教材、紀錄都存在該裝置的瀏覽器。

- 老師在自己的裝置出題後，到「設定 → 只匯出教材」，把 JSON 檔傳給學生，學生用「匯入 JSON」即可更新教材。
- 學生在「學習紀錄 → 傳送學習紀錄給老師」，iPhone 會直接開分享選單（LINE / Email）。老師在「學生狀況 → 匯入學生傳來的紀錄」查看。

### 2. 雲端模式（選配，Supabase 免費方案）

設定 Supabase 後，老師與學生各自註冊，學生的練習紀錄會自動同步，老師在任何裝置登入都能看到所有學生；老師改教材，學生登入後就是最新版。

1. 到 <https://supabase.com> 註冊，按 **New project** 建立專案（Region 選 **Northeast Asia (Tokyo)**，資料庫密碼自己保管好）。
2. 左側 **SQL Editor → New query**，把 `supabase/schema.sql` 整份貼上，按 **Run**。看到 Success 就好（重複執行也安全）。
3. **Authentication → Sign In / Providers → Email**，二選一：
   - **保留 Confirm email（較安全）**：學生註冊後要先到信箱點確認連結，再回網站登入。Supabase 內建的寄信服務每小時只能寄幾封，全班同時註冊可能要分批。
   - **關掉 Confirm email（較方便）**：註冊完馬上能用，但系統不會確認 email 是不是本人的，任何人都可以用別人的 email 註冊。老師要在「學生狀況」確認每個帳號都是自己的學生。
   - 不論哪一種，**全班都註冊好之後**，建議把同一頁的 **Allow new users to sign up** 關掉，陌生人就不能再註冊；有新學生時再暫時打開。
4. **Authentication → URL Configuration**：Site URL 填你的網址（例如 `https://funenglishlearning.com`），Redirect URLs 加上 `https://funenglishlearning.com/**` 和 `https://www.funenglishlearning.com/**`。
5. 按上方 **Connect**（或 **Project Settings → API Keys**），複製：
   - **Project URL**（`https://xxxx.supabase.co`）
   - **Publishable key**（`sb_publishable_` 開頭），或舊版的 **anon public** key
6. 打開 `supabase-config.js`，把 `window.SUPABASE_CONFIG = null;` 換成：

   ```js
   window.SUPABASE_CONFIG = {
     url: "https://xxxx.supabase.co",
     anonKey: "sb_publishable_xxxx"
   };
   ```

   這兩個值本來就是公開的（網頁一定看得到），資料安全靠第 2 步的規則保護。**絕對不要**把 `service_role` / `secret` key 放進網站或傳給任何人。
7. 部署後，在網站上用你的 email 註冊（身分選學生即可）。再回 **SQL Editor** 執行這一行，把你自己升級成老師：

   ```sql
   update public.profiles set role = 'teacher'
   where id = (select id from auth.users where email = lower('你的email@example.com'))
   returning email, role;
   ```

   下方結果出現一列、role 是 `teacher` 才算成功（沒有任何一列表示 email 打錯，或還沒註冊 / 還沒確認 email）。登出再登入後就是老師。

   之後若有其他老師，到「設定」設定老師邀請碼（至少 8 個字，建議 10 個字以上、不要用好猜的字），他們註冊時選「老師」並填這個碼即可。用完把邀請碼清空，就沒有人能再註冊成老師。有人連續猜錯 20 次，邀請碼會自動作廢，重設一個新的就好。

雲端模式的安全規則（都在資料庫裡執行，網頁改不了）：

- 學生只能讀寫自己的紀錄，看不到其他學生。
- 老師看得到所有學生的紀錄，但不能改學生的紀錄；只有老師帳號能改共用教材。
- 同一台電腦換人登入時，前一個人的紀錄不會跑到下一個人的帳號；登出時還沒上傳的練習，會在本人下次登入時補上傳。
- 身分（學生 / 老師）由資料庫決定；邀請碼存在資料庫的 private 區，任何人都讀不到。
- 學生把名字取成奇怪的程式碼也沒用：老師頁面一律當文字顯示。

> 免費專案若連續 7 天沒有人使用會自動暫停（寒暑假可能發生），到 Supabase 後台按 **Restore** 即可恢復。暫停超過 90 天就不能一鍵恢復，放長假前後記得登入看看。
> 想把某位學生改成老師、刪除帳號：Supabase 後台 **Table Editor → profiles** 改 `role`，或 **Authentication → Users** 刪除（紀錄會一起刪除）。

### 選配：讓學生「直接寄給老師」（Resend 寄信服務）

網頁本身不能寄信，所以「📨 直接寄出」是由 Supabase 上的一個小程式（Edge Function `send-report`）透過 [Resend](https://resend.com) 寄出。沒設定之前，學生按下去會看到「老師還沒開啟直接寄信」，其他寄送方式照常可用。

1. **Resend 註冊**（免費方案每天 100 封、每月 3,000 封）。登入後 **Domains → Add Domain**，填 `funenglishlearning.com`。
2. 畫面會列出幾筆 **DNS 記錄**（MX、TXT）。到你買網域的地方（網域在 Vercel 買的就到 Vercel → Domains → DNS Records）照抄加上，回到 Resend 按 **Verify**，等狀態變成 **Verified**（通常幾分鐘到幾小時）。
3. Resend → **API Keys → Create API Key**（權限選 Sending access），複製金鑰（`re_` 開頭，只會顯示一次）。**金鑰請自己保管，不要貼到聊天或程式碼裡。**
4. Supabase 後台 → **SQL Editor**：把最新的 `supabase/schema.sql` 整份再執行一次（會新增寄信紀錄表 `mail_log`，舊資料不會動）。
5. Supabase 後台 → **Edge Functions** → 建立新的 Function，名稱填 **`send-report`**，把 `supabase/functions/send-report/index.ts` 整份貼到網頁編輯器裡，按 **Deploy**。保持預設的「Verify JWT」開啟。（會用 Supabase CLI 的話：`supabase functions deploy send-report`。）
6. Edge Functions → **Secrets**，新增兩筆：
   - `RESEND_API_KEY`：第 3 步的金鑰
   - `MAIL_FROM`：寄件人，例如 `英語學習站 <report@funenglishlearning.com>`（`@` 後面要是第 2 步驗證過的網域）
7. 測試：用學生帳號登入 → 學習紀錄 → 傳送學習紀錄給老師 → 填老師的 Email（要是**本站的老師帳號**的 email）→ 📨 直接寄出。

防止被拿去亂寄信的規則（都在伺服器上執行）：只有登入且 email 已確認的帳號能寄；收件人一定要是本站的老師帳號；每個學生 24 小時內最多 5 封、全站最多 90 封；附件只能是 6 MB 以內的 PDF。老師收到的信裡有學生的名字、帳號 email、想說的話和學習摘要，按「回覆」就會寄到學生填的 email。

## 老師如何出題

1. 用老師帳號登入。
2. **閱讀測驗 → ＋ 新增文章**：填標題、文章、題目（四個選項、勾選正解、解析）。
3. **單字庫 → ＋ 新增單字** 或 **批次貼上**，每行一個：

   brave | adj. | 勇敢的

## 字庫來源

- 7000 單字清單與中文釋義：整理自大考中心高中英文參考詞彙表（社群整理版 [QuantumSamuel/GSAT-vocab](https://github.com/QuantumSamuel/GSAT-vocab) 的 `data/words.json`）。
- 同義字、例句與片語：由 AI 依 B1–B2 程度產生，已自動檢查每筆都有同義字與例句，但未經人工逐筆校對；若發現錯誤，老師登入後可直接在單字庫修改。
- 字根字首字尾：由 AI 撰寫，每一組再由另一位 AI 審查員逐條檢查字源（避免「民間字源」）、拆法、中文與詞性並修正；例字多選自 7000 單字，程度與統測高頻標記取自網站字庫。未經人工逐筆校對，若發現錯誤請告訴網站管理者。
- 世界地圖：Natural Earth 國界（公眾領域）轉成點陣。
- 每日一句：由 AI 撰寫並逐批校對（文法、中譯、去重複）；標註人名的 27 句已人工核對出處，其餘為原創句或常見諺語。

## 每日新聞怎麼更新

- `.github/workflows/news.yml` 每天台灣時間早上 5:41 執行 `scripts/fetch_news.py`，抓取各家 RSS 頭條，寫入 `news.json` 並自動 commit。
- 只保存標題、連結、日期與 RSS 提供的短摘要，點進去會到原新聞網站閱讀。
- 會過濾掉以暴力、犯罪為主的標題，讓內容適合高中生。
- 第一次也可以到 GitHub 的 **Actions → Daily English news → Run workflow** 手動執行。
- 排程只在預設分支執行；本 repo 目前的預設分支就是網站所在的分支。

### 全文＋翻譯（AI 改寫，免費）

- 同一個排程接著執行 `scripts/make_lessons.py`，替**每一則**還沒有文章的新聞：
  1. 讀取原文網頁（`scripts/article_text.py`）當作事實來源；
  2. 請 AI 把整則新聞從頭到尾改寫成 250–400 字、B1–B2 程度的英文文章，每一段附台灣用語的中文翻譯，並整理單字、片語、文法重點。
- **免費做法：Google Gemini 免費額度**
  1. 到 https://aistudio.google.com/apikey 用 Google 帳號登入，按 **Create API key**（免費，不用信用卡）。
  2. 到 GitHub repo 的 **Settings → Secrets and variables → Actions → New repository secret**，Name 填 `GEMINI_API_KEY`，貼上 key。
  3. 到 **Actions → Daily English news → Run workflow** 執行一次。
  - Google 對免費 key 有每日次數上限（約每天數十到數百次，依帳號而定），用完就停，隔天自動接著寫。
  - 免費方案下，Google 可能用送出的內容改善模型；這裡送出的只有公開新聞內容。
- 選用（付費）：若加上 `ANTHROPIC_API_KEY`，就改用 Claude 撰寫（預設每天 6 篇，`LESSONS_MAX`、`LESSON_MODEL` 可調整）。
- 已寫好的文章會保留到那則新聞離開列表為止，所以每天只需要替新的新聞寫文章。
- 為了尊重著作權，網站不轉貼原文：文章用自己的話重寫，程式會檢查不能連續照抄原文 12 個字以上，每篇都附原文連結；原文內容不會存進 `news.json`。
- 程式也會檢查字數、每段都有中文翻譯、單字／片語／文法例句都真的出現在文章裡；不合格的就跳過。
- 每則沒有全文的新聞也有「🌐 整篇中文翻譯」按鈕，會用 Google 翻譯開啟原文的中文版本（不用任何設定）。
- 註：GitHub Models 已於 2026/7/30 停止服務，所以不使用。
